Homework Process 공통 과제 프로세스 — 교실은 종이, 데이터는 과제로

교실에 태블릿이 없어도 됩니다. 답 입력과 오답 학습을 학생 과제로 돌려, 강사 이중작업 없이 데이터가 쌓입니다.

1
교실 — 종이로 응시테스트 4종을 기존 방식 그대로 종이 시험지로 진행 (태블릿 불필요)
2
과제 ① — 답 입력학생이 집에서 본인 기기(폰·노트북·태블릿)로 매쓰홀릭에 답 입력 → 채점·정답률 자동 데이터화
3
과제 ② — 오답 완성 (A/B 반별 선택)A안 매쓰홀릭 안에서 오답·오답유사 과제로 풀기  /  B안 오답 과제를 학습지로 출력 → 종이로 풀고 → 답 기입·다시풀기 완성은 매쓰홀릭에서
✦
결과 — 학생부 자동 축적점수·정답률에 더해 오답 보완 이력("틀린 걸 잡았다")까지 기록됨
Common Rules 공통 규칙 3
  • 1
    채점 마감 = 데이터 마감응시만 하고 채점이 안 끝나면 정답률이 왜곡됩니다. 테스트는 당일 채점 마감이 원칙.
  • 2
    학생 등록 규칙 통일위드아카와 자동 매칭되려면 등록 정보(이름·전화)가 규칙대로 입력되어야 합니다. 등록 양식을 통일합니다.
  • 3
    테스트 명칭 통일일일·주간·단원·과정 — 관마다 이름이 다르면 데이터가 갈라집니다. 4종 명칭을 그대로 사용합니다.
  • 4
    입력 신뢰도 관리점수의 공식 기준은 교실 채점. 집 입력은 기록용이며, 답 베껴 입력을 막기 위해 스팟 체크(무작위 대조)를 병행합니다.
    • To Decide 오늘 정할 것
  • 의무 확정 — 테스트 4종(일일·주간·단원·과정) 전 반 의무, 빈도 확정
  • 오답 과제 방식 — 반별로 A안(온라인) / B안(학습지 출력형) 선택
  • 시작 시점 — 언제부터 의무 적용할지 (예: 다음 주 수업부터)
  • 등록 규칙 — 학생 식별 정보 입력 양식 확정 (연동 전제)
